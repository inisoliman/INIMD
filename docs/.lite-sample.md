# INIMD: محرر Markdown عربي

مرحباً بك في **INIMD**، برنامج عربي أولاً لتحرير ملفات Markdown وتصديرها إلى PDF وWord.

## لماذا INIMD؟

- واجهة عربية كاملة مع دعم الاتجاه من اليمين إلى اليسار.
- معاينة فورية أثناء الكتابة مع فهرس تلقائي للعناوين.
- تصدير PDF بجودة الطباعة، وتصدير Word بأنماط حقيقية.
- يعمل دون اتصال بالإنترنت.

> «الكتابة الجيدة تبدأ بأداة لا تشغلك عن النص.» — مبدأ التصميم هنا.

## جدول المقارنة

| الميزة | INIMD | المحرر التقليدي |
| --- | --- | --- |
| دعم العربية | ✔ كامل | جزئي |
| تصدير PDF | ✔ مدمج | يحتاج إضافات |
| تصدير Word | ✔ docx حقيقي | غير متوفر |
| العمل دون اتصال | ✔ دائماً | غالباً |

## قائمة مهام

- [x] دعم الاتجاه التلقائي
- [x] فهرس العناوين
- [ ] مزامنة سحابية (غير مخطط لها)

## مثال كود

```ts
const greet = (name: string): string => `مرحباً ${name}`
console.log(greet('يا صديقي'))
```

## ملاحظات أخيرة

1. استخدم `Ctrl + S` للحفظ.
2. استخدم `Ctrl + Alt + P` لتصدير PDF.
3. غيّر الخط من الإعدادات لتجربة أفضل قراءة.
